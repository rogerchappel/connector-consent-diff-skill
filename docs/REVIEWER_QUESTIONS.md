# Reviewer Questions

Use these questions when a report includes medium or high risk entries:

- What user-visible workflow requires the new capability?
- Can the scope be narrowed to read-only or a smaller target?
- Which approval mode should gate sends, writes, shell execution, and secret access?
- How will the requester roll back the connector if the new scope behaves unexpectedly?
- Does the manifest describe the permission clearly enough for a future audit?
